# OpenHilo brand assets

Wordmarks and icons used by OpenHilo Studio. Use the supplied assets consistently; preserve their colors, proportions and clear space.

| Use | Asset |
| --- | --- |
| GitHub avatar | [github-avatar.png](github-avatar.png), 500 × 500 |
| README banner | [readme.png](readme.png), 1200 px wide |
| Navigation wordmark | [navbar.png](navbar.png), 600 × 156 |
| Browser tab | [favicon.ico](favicon.ico), plus 16/32/48 px PNG variants |
| Apple home-screen icon | [apple-touch-icon-180.png](apple-touch-icon-180.png) |
| App icon | [app-icon-512.png](app-icon-512.png) |
| GitHub social preview | [github-social.png](github-social.png), 1280 × 640 |

The light artwork should be used on white backgrounds. Preserve its aspect ratio and clear space. Studio retains a separate “Studio” caption below the shared OpenHilo wordmark. Browser copies live in the Studio client's public brand directory; the navigation wordmark is a bundled source asset.

The avatar and social preview assets can be used when configuring a project profile or repository preview on GitHub.
